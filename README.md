# Rosa's Delivery Promise Finder

A Streamlit app that recommends the profit-maximising promised delivery time for each zone and time block of Rosa's Pizza (BUSADMIN O712, Assignment 1).

- `app.py`: Streamlit interface
- `rosa_logic.py`: decision logic carried over from the analysis notebook
- `.github/skills/notebook-to-streamlit/SKILL.md`: Copilot skill used to build the app from the notebook

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
